# vehicle-class-attribute-demo
A Python OOP project demonstrating shared class attributes and instance attributes. It creates multiple Vehicle objects, displays their default shared color, and shows how changing the class attribute updates all instances that have not overridden it.
<br>
Topics Covered:
<br>

1. Class and Object
2. Class Attributes
3. Instance Attributes
4. Constructor (__init__)
5. Instance Methods
6. User Input (input())
7. Type Conversion (int())
8. Accessing Class Attributes
9. Modifying Class Attributes
10. self Keyword
11. String Formatting (f-strings)
12. Shared Attributes Across Multiple Instances
